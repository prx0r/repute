# Crypto-Agent Ecosystems — 2026-08-28

## Four Machine-Work Markets

```
1. WORK MARKETS       "Do this task → get paid"
   NEAR, Virtuals, OpenServ

2. SERVICE MARKETS    "Expose capability → get paid per use"
   Olas Mechs, Virtuals ACP, Bankr x402, Nevermined

3. INCENTIVE MARKETS  "Be the best implementation → earn emissions"
   Bittensor (129 subnets), Allora, FLock

4. RESOURCE MARKETS   "Provide compute/infrastructure → get paid"
   Akash, Nosana, Morpheus
```

## Top 5 for Moltwork

### 1. Bittensor — 129 subnets, incentive competitions
- API: https://api.metagraph.sh/api/v1/subnets/{netuid}/metagraph
- Data: subnet, category, emissions, miners, validators, scores
- Ditto SN118: agent memory/tool-use competition

### 2. NEAR Agent Market — work tape already crypto-native
- API: https://market.near.ai/api-docs/
- Data: jobs, bids, agents, reputation, earnings, outcomes
- Real bid → award → delivery → payment data

### 3. Virtuals ACP — agent-to-agent commerce telemetry
- Scanner: https://app.virtuals.io/acp/scan/agents
- Data: agents, offerings, jobs, buyers, success rate, aGDP/revenue
- ACP v2: structured schemas for requirements/deliverables

### 4. Olas Mech — x402-like services with history
- API: https://stack.olas.network/mech-client/
- Data: mech, tool, requests, deliveries, price, earnings
- Subgraph: on-chain queries for marketplace data

### 5. OpenServ Ideaboard — ideas → x402 endpoints
- API: https://api.launch.openserv.ai
- Data: ideas, tags, pickups, shipments, x402 URLs
- Agents ship implementations as x402 services

## Also Important

### Bankr — deployment backend for Moltwork Factory
- Docs: https://docs.bankr.bot/
- Data: endpoints, prices, requests, revenue
- x402 Cloud: deploy capabilities as paid endpoints

### Phala — confidential agent infrastructure
- API: https://cloud-api.phala.network/docs
