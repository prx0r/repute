# 8004scan — Source Reference

**URL:** https://8004scan.io
**Status:** Live, production (467K+ registered agents)
**Agent-friendly:** Yes (ERC-8004 registry)
**Payment:** Varies (x402, on-chain)
**Fee:** N/A (registry/discovery)

## Overview

The canonical registry for AI agents on ERC-8004. Identity Registry (ERC-721), Reputation Registry (on-chain feedback), Validation Registry (TEE/zkML proofs). 467K+ registered agents, 557K+ feedback submitted, 435K+ unique wallets.

## API Surface

### Key Data Points
```
GET /agents                         # Browse agents
GET /agents/{address}               # Agent profile
GET /leaderboard                    # Top agents
GET /networks                       # Network activity
```

## ERC-8004 Standard
- Identity: ERC-721 portable identifiers
- Reputation: on-chain feedback + off-chain scoring
- Validation: TEE attestations, zkML proofs, staking
