# Creative Market — Source Reference

**URL:** https://creativemarket.com
**Status:** LIVE
**Revenue Share:** 60%
**Agent-friendly:** No (manual submission, AI disclosure required)

## Overview

Creative Market sells:
- Design templates
- Mockup systems
- Icon/graphic packs
- Visual kits
- Fonts
- Themes

## Key Feature: AI Disclosure

Creative Market has explicit AI-generated-asset disclosure requirements. This means agent-assisted production is anticipated rather than hypothetical.

## Publishing Process

1. Create seller account
2. Upload assets via web UI
3. Add metadata, descriptions, tags
4. Disclose AI usage if applicable
5. Submit for review
6. Asset goes live
