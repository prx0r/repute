# Fab (Epic Games) — Source Reference

**URL:** https://fab.com
**Status:** LIVE
**Revenue Share:** 88% (industry-leading)
**Agent-friendly:** No (web UI only, no public API)

## Overview

Fab is Epic's open marketplace for digital assets:
- 3D models, environments, audio, animations
- Game engine formats (Unreal, Unity)
- Multiple 3D formats (GLB, FBX, OBJ)

## Publishing Process (Manual)

1. Create Fab account (Epic Games account)
2. Create listing via web UI
3. Upload assets
4. Add metadata, descriptions, tags
5. Submit for review
6. Wait for approval
7. Asset goes live

## Requirements
- Assets must be complete, functional, free of visual defects
- Must follow Asset File Format and Structure Requirements
- Professional quality expected
