# Canva Creators — Source Reference

**URL:** https://www.canva.com/creators
**Status:** LIVE
**Revenue Share:** Royalty-based (usage payments)
**Agent-friendly:** No (manual submission)

## Overview

Canva Creators program for:
- Templates
- Graphics, icons, clipart
- Backgrounds
- Video elements
- Photos

## Submission Process

1. Apply to Canva Creators program
2. Create content following Canva guidelines
3. Submit via Canva's creator portal
4. Content reviewed by Canva team
5. If approved, earn royalties when users use your content

## Requirements
- Must be accepted into Creators program
- Content must meet Canva's quality standards
- AI-generated content must be disclosed

## Data Fields Available (from public listings)

| Field | Available | Notes |
|-------|-----------|-------|
| title | ✅ | Template/element name |
| category | ✅ | Templates, Graphics, etc. |
| usage_count | ✅ | How many times used |
| designer | ✅ | Creator name |

## Limitations
- No public API
- Manual submission
- Royalty-based (not per-sale)
- Requires acceptance into program
